======================================================================
WHAT THESE DOCUMENTS ARE
======================================================================
A state SNAP agency asks FNS/FNA to waive the ABAWD work-time-limit (the 3-in-36
month rule) for specified geographic areas where jobs are insufficient. FNS
records its decision on a "Waiver Response" form (numbered fields) and/or a
decision letter. Many documents are scanned images of forms; some are typed
tables listing dozens of counties/cities. Read carefully; transcribe names and
numbers exactly as printed (preserve original spellings and apparent typos in
geographic-unit names). Every geographic unit keeps its verbatim printed string in
orig_text; see GEOGRAPHIC UNITS below for how name / area_type / orig_text split.

======================================================================
DOCUMENT STRUCTURE: request_level + groups
======================================================================
- request_level: fields describing the whole request/response (serial number,
  type of request, state, region, the FNS action text, and the form's dates).
- groups[]: one entry per set of areas evaluated TOGETHER under a common rule and
  a common action. Each group carries its geographic_units[] plus the rule,
  evidence, and dates for that set.

======================================================================
HOW THE AREAS WERE EVALUATED (qualification_level)
======================================================================
This is the field most often gotten wrong, and the one downstream analysis
depends on most. Read this section slowly.

Areas printed together in one sentence were NOT necessarily evaluated together.
A document may list ten counties because they share a rationale, or because the
state deliberately bundled them so that weak members ride along on the set's
combined numbers. These are different facts about what the state DID, and the
document will usually not tell you which one it is. You have to work it out.

The question to answer for every set of areas is a counterfactual:

    IF THIS AREA WERE LISTED BY ITSELF, WOULD IT STILL QUALIFY
    UNDER THE RULE THE DOCUMENT CITES?

  - Yes for every area in the set   -> per_unit
  - No for even one area            -> joint_aggregate
  - The state qualifies as a whole  -> statewide
  - Cannot be determined            -> unknown

DO NOT look for a sentence that announces the answer. There usually isn't one.
Reason from the rule and from the numbers.

WHAT THE RULE ITSELF SETTLES. For most criterion codes the answer follows from
how the rule works, no matter how the sentence is phrased:

  lsa               DOL confers Labor Surplus Area status on an individual area.
                    One area's designation cannot depend on another's. So "Ashe,
                    Columbus, Edgecombe, Robeson, Rutherford, Scotland and Vance
                    ... based on their designation as LSAs" states SEVEN
                    independent facts, not one joint finding -> per_unit, seven
                    groups. Note the document says only that they ARE LSAs; it
                    never says each was designated separately, and it does not
                    have to. You are expected to know how the rule works.
  pct10_statutory   The area's own unemployment rate. -> per_unit.
  eb_trigger        Qualification attaches to the whole state. -> statewide.
  federal_suspension  Nationwide, no area test. -> statewide.
  noncontig_1p5x    Statewide rate test. -> statewide.
  pct20_above_natl  Computable at EITHER level. See below.
  other             Usually per_unit, but check as for pct20_above_natl.

WHERE THE REAL JUDGMENT LIES: pct20_above_natl (and 'other'). A state may apply
the 20% test to one county's own rate, or to a combined rate over a set of
counties. It will often compute the combined figure and simply present the
result, saying nothing about how it was derived. Weigh the evidence:

  1. STRONGEST: an area whose own printed rate falls BELOW the stated threshold,
     yet is listed and approved anyway. Nothing but aggregation could have
     carried it. -> joint_aggregate. Do this arithmetic — compare each printed
     area rate against the printed threshold — whenever the document gives you
     both. It is the most reliable signal available and it does not depend on
     the document explaining itself.
  2. STRONG: the document treats the set as an object — gives it a name ("the
     Northeast region", "70 County Group", "seven multi-county areas"), prints a
     combined labor-force or unemployment total for it, or prints one rate for
     the set. A state that constructed and named a set was choosing a bundle.
  3. The document prints a rate for each area, every one clears the threshold,
     and there is no set-level name or total. -> per_unit.
  4. None of the above resolves it -> unknown. Say in
     qualification_level_evidence exactly what you could not determine. Do not
     guess, and do not default to one group because it is tidier.

  Corroborating (never decisive on its own): areas in a genuine bundle are
  normally geographically contiguous — since 2016, FNS requires a jointly
  evaluated group to be contiguous OR to constitute an economic region. Check
  candidate bundles against the county adjacency lists in the state geography
  reference file provided with each document instead of guessing from names
  (sub-county areas: reason via their parent counties). A set scattered across
  opposite ends of the state is more likely a shared rationale than a
  constructed bundle. If a named set is plainly non-contiguous, keep the set as
  the document draws it and note the tension in criteria_summary_text.

SCOPE OF A JOINT SET. When a set is joint_aggregate, the group contains EVERY
area the state placed in it — including areas that would also have qualified on
their own. Do NOT split a named region into "would have qualified alone" and
"carried by the group" sub-groups. The state drew that set deliberately, and the
strong members are precisely what let it include the weak ones; splitting it
destroys the choice the state actually made.

======================================================================
SPLITTING RULE
======================================================================
Emit a separate group for each distinct combination of:
  (a) qualifying rule (criterion_code),
  (b) action (approved / denied / other), and
  (c) evaluated set.

For per_unit sets, (c) means ONE GROUP PER AREA. Six LSA counties approved
together = six groups. For joint_aggregate, one group per constructed set; a
document with seven named multi-county regions has seven groups. For statewide,
one group.

Still split on rule and action as before: WI FY2003 (serial 2020071) approves
some counties as Labor Surplus Areas and others under the 20% rule, so those
never share a group even though they share a serial.

Do NOT create extra groups merely to hold a per-area unemployment rate — that
belongs on the geographic unit itself (unemployment_rate / qualifying_basis).

DENIED AREAS follow the same logic. A state that requested twenty counties
individually and had them all turned down yields twenty denied groups, not one:
the areas were never evaluated as a set. Only when the document denies a
constructed set AS a set does a denial become a single multi-area group.

BOTH SHAPES ARE COMMON — expect to produce both, sometimes in one document, and
do not let the group count alarm you:
  - a document approving 16 Labor Surplus Area counties, 13 counties on their own
    20%-rule rates, and denying 50 more is 79 groups of one area each;
  - a document approving one 20-county bundle on the bundle's combined rate is
    ONE group holding 20 areas.
A high group count is the correct output for a per_unit document. Never merge
areas into one group to keep the JSON short.

Record how you decided: put the verbatim text, or a one-line statement of the
arithmetic you did ("Cleveland 6.1 is below the 6.3 threshold yet approved"),
into qualification_level_evidence. Put the document's own name for a joint set
into bundle_label, else null.

Set request_level.number_of_groups = len(groups).

======================================================================
CRITERION CLASSIFICATION (canonical codes from the rules KB)
======================================================================
Classify the rule the document INVOKES for each group into criterion_code, and
also copy the document's own wording into criterion_verbatim. Codes:

  pct10_statutory   Area unemployment rate over 10 percent (statutory "10% Rule").
  pct20_above_natl  Area 24-month avg rate at least 20% ABOVE the national average
                    ("20% Rule" / "insufficient jobs" by the 20%-above test).
  lsa               Area is a DOL-designated Labor Surplus Area (LSA). Language like
                    "labor surplus area", "designated LSA", "20 CFR 654".
  eb_trigger        Area/state qualifies via Extended Benefits / EUC / "extended
                    unemployment benefits" (EUB) trigger (IUR/TUR). Often statewide.
  federal_suspension  Nationwide statutory suspension, NO area test: ARRA
                    (Apr 2009-Sep 2010) or FFCRA/COVID (Apr 2020-Jun 2023).
  noncontig_1p5x    Noncontiguous state (AK/HI) statewide rate >= 1.5x national
                    (OBBB 2025 onward only).
  other             Softer "insufficient jobs" evidence with no fixed threshold:
                    low/declining employment-to-population ratio, declining
                    industry/occupation, an academic study or publication.
  null              Cannot determine the rule.

Guidance:
- Recognize, don't re-derive. If FNS says the area is an LSA, code lsa even if
  the letter doesn't restate the unemployment math.
- "20 percent above the national average" -> pct20_above_natl, NOT pct10_statutory.
  A bare "over 10 percent" / ">10% unemployment" -> pct10_statutory.
- Effective-date sanity check (flag internal inconsistencies in criteria_summary_text,
  do not silently drop): pct20_above_natl and lsa exist FY-wide from 1996 until the
  OBBB (2025) repeal; federal_suspension only in the ARRA and FFCRA windows;
  noncontig_1p5x only FY2026+. If a document invokes a rule outside its window,
  extract what it says and note the tension.

======================================================================
FEDERAL SUSPENSION WINDOWS: how to code action and scope
======================================================================
During a nationwide statutory suspension the ABAWD time limit is not in force
anywhere, so the state IS covered for that period no matter what it asked for
or how FNS worded its reply. The authoritative windows (rules KB, 002_rules_machine):

    ARRA    P.L. 111-5, sec 101(e)     2009-04-01  ->  2010-09-30
    FFCRA   P.L. 116-127, sec 2301     2020-04-01  ->  2023-06-30

  FFCRA's end date is tied to the public health emergency. Do NOT substitute the
  CAA-2023 cutoff (emergency ALLOTMENTS ended after Feb 2023 under FFCRA sec 2302)
  — that is a different provision and does not end the ABAWD suspension.

This is a general rule, not a fact about one fiscal year: it applies to ANY state
and ANY document whose fiscal year overlaps either window (ARRA reaches FY2009 AND
FY2010; FFCRA reaches FY2020 through FY2023).

When a document's disposition rests on such a suspension (criterion_code =
federal_suspension), code the group as:

    group_action         "approved"        <- NOT null
    qualification_level  "statewide"
    geographic_units     exactly ONE unit: the STATE itself
                         name      = the state's own name (e.g. "Wisconsin")
                         area_type = "statewide"

Two traps this exists to prevent:

1. FNS letters in these windows routinely APPROVE AND DENY NOTHING — they say the
   request is "no longer necessary", moot, or superseded, because the statute has
   already done the work. Do not read that as absence of coverage and do not leave
   group_action null. The operative fact is that the state's ABAWDs are time-limit
   free for the window. Record "approved", and preserve FNS's actual wording
   verbatim in action_reason_approval_denial and criteria_summary_text so the
   "no longer necessary" character of the decision is not lost.

2. The suspension is nationwide, but DO NOT name the unit "United States" or set
   area_type "national". These records are assembled into a state-by-state panel;
   emit one statewide row under the state's own name. The nationwide scope belongs
   in criteria_summary_text / qualification_level_evidence, not in the unit name.

If the document ALSO narrates a separate qualifying route (e.g. the state was
independently EB-trigger eligible but did not pursue it), that is context, not a
second group: keep it in criteria_summary_text unless FNS took a distinct action
on it.

======================================================================
GEOGRAPHIC UNITS: name / area_type / orig_text + BLS-LAUS classification
======================================================================
For each geographic unit, emit three name fields and two classification flags.
- orig_text: the unit EXACTLY as printed, including the trailing type word and any
  spelling/typo (e.g. "Eau Claire city", "Balance of Adams County", "Bad River
  Reservation"). This is the ground-truth anchor; never omit it.
- name: the core place name with the trailing type word removed ("Eau Claire",
  "Adams", "Bad River"). Preserve the document's spelling UNLESS it is within a
  character or two of exactly one name in the state geography reference file —
  then use the reference spelling here (e.g. printed "Pasguotank" -> name
  "Pasquotank"; the verbatim print stays in orig_text). Never force a match: if
  nothing in the reference is close, keep the printed spelling. The reference
  is a starting point, not an exclusive list — an area's absence from it is not
  evidence of a transcription error.
- area_type: the unit type when stated or inferable (county, city, parish, borough,
  census area, reservation area, LMA, independent city, planning region, town,
  balance of county, statewide, national); else null.

non_standard_geography (boolean): true when the unit has NO clean single BLS/LAUS
published series. Standard LAUS units (set false) are the geographies BLS publishes
unemployment estimates for: census regions/divisions; states, DC, Puerto Rico; OMB
federal statistical areas (metropolitan statistical areas, metropolitan divisions,
micropolitan areas, combined statistical areas, and pre-2025 New England
NECTAs/NECTA divisions); small labor market areas; counties and county-equivalents
(parishes, boroughs, Alaska census areas, independent cities, Connecticut planning
regions, Puerto Rico municipios); cities/places with population >= 25,000; all New
England cities and towns regardless of size; and "balance of county/state" residual
series. Set true (and give a short non_standard_geography_note) for anything else:
tribal reservations, sub-city neighborhoods/wards, ZIP codes, school districts,
census tracts, sub-25,000 non-New-England places, and custom/partial-area carve-outs.
NECTA rule: for documents dated before 2025, treat New England NECTAs and NECTA
divisions as STANDARD (they were published then, though later discontinued). Default
to false; use null only when the unit text is too illegible to classify.

balance_of_county (boolean): true if the unit is the "balance of" a county — the
county minus its separately-listed cities/towns ("Balance of X County", "remainder
of X", "X County excluding ..."). A balance-of-county area is itself a standard LAUS
series, so keep its non_standard_geography = false. Default to false; use null only
when the unit text is too illegible to classify.

======================================================================
SOFTER "INSUFFICIENT JOBS" LANGUAGE (per group)
======================================================================
FNS's 1996 guidance allowed waivers for areas with a "lack of jobs due to lagging
job growth" or a "lack of jobs in declining occupations or industries" — soft
standards with no numeric threshold. Set soft_criterion_invoked = true whenever this
kind of language (including a declining employment-to-population ratio or a cited
study) appears in the applicant's or FNS's rationale, EVEN IF a hard criterion (20%
rule, LSA, EB) is also cited, and copy the phrase into soft_criterion_verbatim. This
flag is INDEPENDENT of criterion_code: criterion_code stays the hard rule that was
used, or 'other' only when the soft rationale is the sole basis. false if only
threshold/designation criteria appear; null if the rationale text is absent.

======================================================================
NON-CONFORMING DATA (per group)
======================================================================
The 2006 guidance requires non-seasonally-adjusted BLS/LAUS figures under a
standardized 24-month averaging and rounding procedure. In data_nonconformance,
flag any departure the document REVEALS — FNS often names it explicitly when
rejecting: non_bls_source (a non-BLS data source), seasonally_adjusted (SA figures),
nonstandard_averaging (a window/average/rounding other than the standard 24-month
non-SA procedure), older_vintage (explicit reliance on an older BLS vintage). Set a
flag true only on affirmative evidence, false when the conforming practice is shown,
and leave the whole object null when the document gives no data-methodology detail
for the group. Put brief support in note.

======================================================================
DOUBLE-COUNTING CHECK (request level)
======================================================================
After forming groups, check whether any single geographic unit appears in MORE THAN
ONE group (banned since the 2006 guidance). Count near-duplicates: a county and its
own "balance of" remainder, or spelling variants of the same place. If found, set
request_level.possible_double_counting = true and name the unit(s) and groups in
double_counting_note; otherwise false. Use null only for non-conforming, zero-group,
or single-group documents where the check is moot.
